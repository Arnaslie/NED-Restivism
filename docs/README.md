# Docs

Where we record why the project is the way it is.

- `decisions/` — one file per decision (lightweight ADRs). Numbered, never rewritten: if a decision changes, add a new file that supersedes the old one.
- `ideas.md` — running list of ideas, not yet decided.

## Decision template

Copy into `decisions/NNNN-short-title.md`:

```md
# NNNN. Title

- Status: accepted | superseded by NNNN
- Date: YYYY-MM-DD

## Context
What problem or constraint prompted this.

## Decision
What we chose.

## Consequences
What gets easier, what gets harder, when to revisit.
```
